    1. Select the Travel 2026 notebook

    Where your notes live

    By default: ~/Documents/Driftwood. Reveal it with DriftwoodShow Library in Finder.

    By default: ~/Driftwood. Reveal it with FileOpen Library Folder.

    Settings worth changing

    Autosave delay800 msSettingsEditor

    How long Driftwood waits after you stop typing before saving. Lower it if you're on a flaky laptop battery.

    Spellcheck languagesystemSettingsEditor

    Follows your OS language unless set. Set it explicitly if you write in a second language.

    When something goes wrong

    Could not save "Trip packing list": EACCES permission denied

    What it means

    Your computer refused to let Driftwood write to the library folder — usually because the folder was moved into a protected location.

    How to fix it

    Choose SettingsLibraryChange… and pick a folder inside your Documents.
    This note was changed outside Driftwood. Reload?

    What it means

    Another app (or a sync tool) edited the file while it was open here.

    How to fix it

    Click Reload to take the newer version. Your in-app edits are kept in EditRestore Previous.

    Spot the mistake: Sam wants their notes on a new laptop

    1Install Driftwood on the new laptop
    2Delete the library folder from the old laptop
    3Copy the library folder to a USB stick
    4On the new laptop: Settings › Library › Change… and pick the copied folder

    Library mode: code ↔ English

    Codeexamples/export.ts 
    const doc = await driftwood.open("notes/trip.md");
const pdf = await doc.export("pdf", { theme: "paper" });
await fs.writeFile("trip.pdf", pdf);
    Plain English

    Load a note from disk and wait until it's ready.

    Render it to PDF using the "paper" theme — the same one the app uses.

    Save the resulting bytes as a file.

    methoddoc.export(format: "pdf" | "html", options?: ExportOptions): Promise<Uint8Array>

    Renders the document in the requested format. Throws ExportError if the note contains an image that can't be read.

    ParameterDescription
    formatOutput type. Only these two values are accepted.
    options.themeoptionalTheme name. Defaults to "paper".

    ReturnsThe file contents as bytes.

    Don't
    doc.export("pdf");  // forgot await

    You get a Promise, not the bytes — the file will be empty.

    Do
    await doc.export("pdf");

    Wait for the render to finish before using the result.
